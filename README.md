## What I am building

### Token Meter (iOS, solo project)

An iOS app that shows how much of your AI usage quota is left across Claude, Codex, OpenRouter, and Google Drive, as progress bars on a dashboard and a home screen widget. Everything runs on the phone, with no backend.

I built it from an empty Xcode project, one feature per branch and pull request. Working on it, I learned to:

- call real REST APIs with async/await and Codable, and map four different responses into one shared model
- build three kinds of sign-in: API key, OAuth 2.0 with PKCE, and OAuth device code
- keep credentials in the Keychain and share data with a WidgetKit widget through an App Group
- use typed errors, so the app offers Reconnect for a sign-in problem and Retry for a network problem
- structure the app in MVVM and write unit tests with Swift Testing

It is the iOS version of an existing Android app, [ai-usage-android](https://github.com/ateymoori/ai-usage-android) by AmirHossein Teymoori. I took the idea, the provider list, and the design from there, and wrote the iOS app myself.

Repo: [github.com/Nedakhalaj/token-meter-ios](https://github.com/Nedakhalaj/token-meter-ios)

### FilmShelf (React, school project)

A movie shop web app built with React and the TMDb API. You can browse Now Playing, Popular, and Top Rated movies, search, open a detail page for each film, and add or remove movies in a shopping cart. It shows a spinner while data loads and a clear message when something goes wrong.

It is my first React project: function components with props, useState and useEffect, and React Router for the pages.

Repo: [github.com/Nedakhalaj/FilmShelf](https://github.com/Nedakhalaj/FilmShelf)
